# Quantum Many-Body Dynamics on IBM Quantum Hardware using Qiskit

This repository contains the implementation of quantum many-body dynamics simulations on IBM Quantum superconducting processors using Qiskit. The project explores the behavior of interacting spin Hamiltonians on NISQ (Noisy Intermediate-Scale Quantum) devices through quantum circuit-based simulations and hardware execution.

## Implemented Models

* Fermi-Hubbard Hamiltonian
* Floquet Hamiltonian
* Dzyaloshinskii-Moriya Interaction (DMI) Hamiltonian
* Lipkin-Meshkov-Glick (LMG) Hamiltonian

## Features

* Hamiltonian simulation using Suzuki-Trotter decomposition
* Quantum state tomography
* Fidelity analysis
* Density matrix reconstruction
* Quantum hardware execution on IBM Quantum
* Noise and performance characterization

## Technologies

* Python
* Qiskit
* IBM Quantum
* NumPy
* SciPy
* Matplotlib
